# AI Site Memory

AI Site Memory is a construction-project intelligence application. Phase 1 is an **Ask the Project** AI Status Desk that lets authorized project users ask natural-language questions about project information and receive evidence-backed answers.

## Product thesis

> Ask the project instead of asking the person who knows the project.

## Documentation

- `docs/PDD.md` — approved product discovery baseline
- `docs/PRD.md` — approved product requirements and roadmap
- `docs/TECHNICAL_BUILD_SPEC.md` — Phase-1 architecture and implementation guidance
- `docs/OPENCODE_FIRST_PROMPT.md` — first implementation instruction for the coding agent
- `AGENTS.md` — repository-wide coding-agent instructions

## Data policy

This public repository contains only source code, documentation, and synthetic/demo construction data.

Never commit real company project data, drawings, correspondence, credentials, API keys, tokens, client information, or other confidential material.

## Intended product evolution

Memory → Understand → Answer → Monitor → Predict → Act
